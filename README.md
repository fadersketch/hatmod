# 神之牛仔帽（HatMod）

![黑帽「预知」：蓄力完成的一刻，视野整段变为黑白](https://cdn.jsdelivr.net/gh/fadersketch/hatmod@ca78d556850c64b703642c1473bab11cc18ac12c/gallery/01-black-hat-foresight.jpg)

一个 Minecraft 模组：三顶**牛仔帽**（黑 / 白 / 红）。戴上之后会像手电筒一样，
对着面前的敌人**持续照射一道光柱**，并附带各自专属的技能与附魔。

一个模组，两棵源码树，分别对应两个模组加载器：

| 目录 | 游戏版本 | 加载器 | Java |
| --- | --- | --- | --- |
| [`hatmod-forge-1.20.1/`](hatmod-forge-1.20.1) | Minecraft 1.20.1 | Forge 47.x | 17 |
| [`hatmod-neoforge-1.21.1/`](hatmod-neoforge-1.21.1) | Minecraft 1.21.1 | NeoForge 21.1.x | 21 |

两棵树的玩法内容一致，只是适配不同的加载器。每棵树目录里都有一份**更详细的设计文档**
（`README.md`），包含全部实现细节与可调参数。

## 三顶帽子

| 帽子 | 蓄力 | 照射 | 每刻附加伤害 | 专属效果 |
| --- | --- | --- | --- | --- |
| **黑色** | 22 秒（440 刻） | 8 秒（160 刻） | **10** | 蓄力期间**受到伤害就瞬移躲开那一击（完全免伤）**，每轮最多 3 次（末影系传送特效 + 音效 + 屏幕提示剩余次数） |
| **白色** | 18.2 秒（364 刻） | 6.45 秒（129 刻） | **10** | **永久迅捷 I + 跳跃 I**（戴着就一直有，摘帽即消失） |
| **红色** | 29.4 秒（588 刻） | 7.6 秒（152 刻） | **10** | 照射期间**力量 I** |

> 「每刻附加伤害」是生存向的低值，光柱真正的压力来自「每刻扣目标当前生命的 **5%**」那一部分，
> 固定值只负责收尾。

三顶帽子在游戏里统一叫**「神之牛仔帽（黑/白/红）」**，物品提示写着**「神本无相」**。

### 合成

三顶帽子都是**有序合成**，对应颜色的染料 + 皮革 + 下界之星：

```
L L L
L D N
N N N
```

`L` = 皮革 ×4，`D` = 对应颜色的染料（黑/白/红），`N` = 下界之星 ×4。

## 一个完整的循环

戴上牛仔帽（头盔槽，或 Curios 饰品栏的 head 槽）后进入自动循环。
**任何生物**戴上都会生效 —— 玩家、车万女仆、其他模组的生物都一样。

```
        ┌──────────────────────────────────────────────────┐
        │                                                  │
        ▼                                                  │
  ① 合法目标进入 16 格（没有目标就不会进入蓄力）                  │
        │                                                  │
        ▼                                                  │
  ② 蓄力（黑 22s / 白 18.2s / 红 29.4s）                        │
     · 【循环开始】播放这顶帽子的音乐（位置在戴帽者身上、可衰减）     │
     · 索敌与攻击照常（蓄力不禁止攻击，也不压制索敌）                │
     · 戴帽者自身固定获得「抗性提升 II」                          │
     · 自身以外 5 格内：生物缓慢 V + 整体压速（时间变慢，方向不变）    │
     ·            　 　 箭矢等弹射物关掉重力、沿原方向极慢飞行        │
        │                                                  │
        ▼                                                  │
  ③ 蓄力结束的瞬间                                            │
     · 范围减速**全部解除**，周围生物立刻恢复自由                  │
     · 获得「迅捷 II」（到循环结束）+ 信标音效                   │
        │                                                  │
        ▼                                                  │
  ④ 持续照射（黑 8s / 白 6.45s / 红 7.6s）                      │
     · 光柱【每道各锁一个不同的敌人】，更近的会顶掉旧的（会转火）      │
     · 被光罩住的敌人每刻吃「按血量算」的伤害（无视护甲）           │
     · 同时获得「缓慢 255」，完全动不了                          │
     · 红帽：期间自身力量 I                                     │
        │                                                  │
        ▼                                                  │
  ⑤ 附近还有敌人？ ── 是 ──> 回到 ②（循环开始，音乐重放）──────────┘
                   └─ 否 ──> 回到待机（音乐停止）
```

### ① 和平主义（一直生效，与循环无关）

戴上帽子后**无法攻击被动生物**（牛羊猪鸡兔猫…）和**未被激怒的中立生物**
（狼、羊驼、铁傀儡、蜜蜂、末影人、僵尸猪灵…）。敌意生物、以及被激怒/已锁定你的中立生物照常可以打。
这一条是帽子本身的属性，不随蓄力 / 照射切换。

### ② 蓄力阶段

**合法目标进入 16 格**即开始蓄力（一个合法目标都没有时不会进入蓄力）。

「合法目标」由 `HatAbilities.isEnemy` 一个函数说了算，**四类都算**：

| 算合法目标 | 说明 |
| --- | --- |
| 敌意生物 | 僵尸、骷髅、苦力怕…（`Enemy`） |
| **被激怒的中立生物** | 怒气还没消（`NeutralMob#getRemainingPersistentAngerTime > 0`）就算，不需要它正在打你 |
| 正在锁定戴帽者的生物 | 不看类型：`getTarget()` 指向戴帽者就算 |
| **最近真的打过戴帽者的生物** | 兜底：对戴帽者造成了 **>0 的伤害**之后，**10 秒**内一律算敌人（伤害为 0 的「攻击」不算，例如打雪仗的雪球） |

> 最后一条是给「名义上不是敌人、实际上会动手」的生物兜底 —— 例如被魔改过的野生女仆。
> **己方永远除外**（主人、同一主人的女仆/宠物、同队成员），玩家也永远不算。

蓄力期间：

- 以自己为中心、**半径 5 格内**，除自己以外：
  - **生物**：缓慢 V（−75% 移速）+ 三轴同系数的整体压速 —— 沿原路慢慢走，方向不变。
  - **弹射物**（箭矢、雪球、三叉戟…）：**关掉重力**，压到 0.12 格/刻，沿原方向慢慢飞。
  - **其它非生物实体**（掉落物、下落的方块、TNT…）：三轴同系数压速到 50%。
  - **己方一律跳过**（见下）。
- **戴帽者自己固定获得抗性提升 II**，蓄力全程挂着、一结束立刻收掉。

#### 己方后门（女仆戴帽子不能把主人一起按住）

`HatAbilities.isFriendlyTo` 是唯一的「自己人」判据，命中任何一条就算己方：
**同一个主人** / **被戴帽者自己驯服的** / **同一计分板队伍**。
走的是原版 `OwnableEntity#getOwnerUUID` —— 车万女仆的 `EntityMaid` 继承 `TamableAnimal`，
而 `TamableAnimal` 就是 `OwnableEntity`，所以不需要硬依赖女仆模组。
光柱「神隐」的队友判定、以及「掌控」内讧挑对手也都走这一个函数。

### ③ 蓄力结束

同一刻：撤掉 5 格内的减速力场、获得「迅捷 II」（挂到本轮结束）、播放信标音效，
以及附魔「预知」（若附了）在**这一刻**释放。

### ④ 持续照射

不是「打一发」，而是**持续照射**并**自动锁定最近的敌人**（射程 24 格，出现更近的就立刻转火）。
一道光只打它锁定的那一个；红帽「光柱」附魔可以同时打多道，各打各的。

被照中的敌人**每刻（1/20 秒）**受到一次伤害，无视护甲：

```
固定伤害：该帽子的 damagePerTick（三顶统一默认 10）—— 走正常的 hurt()
附加伤害：目标当前生命值 × 5%                —— 直接 setHealth 改血，绕过一切减伤
```

- 伤害类型是本模组的自定义类型 **`hatmod:flash`**，造成者记成戴帽者（击杀算他的）。
  它挂进了 `minecraft:bypasses_invulnerability` 标签，所以「受击无敌帧 / 单次伤害上限」也拦不住它。
- 附加的 5% 直接 `setHealth`，是**强制百分比伤害**；但只改血不触发死亡，
  所以目标血量低于最大生命的 **5%** 后就不再扣附加伤害，把收尾让给固定伤害走正常死亡流程。
- 被照中的敌人同时获得**缓慢 255**、速度归零，**完全动不了**。
- **其他生物戴帽子时，玩家也能看到它的光柱**（对每个戴帽子的生物各画一条）。

## 专属附魔（每顶帽子 3 个）

三顶帽子对**原版所有头盔附魔**都兼容（保护、爆炸保护、弹射物保护、火焰保护、水下呼吸、
水下速掘、荆棘、耐久、经验修补、绑定诅咒、消失诅咒……），走正常的 `ARMOR_HEAD` 通道。

除此之外，每顶帽子还各有 **3 个专属附魔**，只有对应的那顶帽子能附上（注册名 `hatmod:<id>`，等级上限 III）：

| 附魔 | id | 帽子 | 每级效果 | III 级时 |
| --- | --- | --- | --- | --- |
| 闪避 | `formless` | 黑 | 每轮瞬移闪避 +1 次 | 3 → 6 次 |
| 残影 | `afterimage` | 黑 | 照射期每轮多 1 次瞬移闪避，躲开的那一击**完全落空** | 1 → 3 次 |
| 预知 | `soul_reap` | 黑 | **蓄力完成的那一刻**释放：把 30 格内的敌人定在原处，时长按等级取「本轮循环剩余长度」的 1/3、2/3、3/3；视野**整段变为黑白渲染**，浮现「我早已料到」 | 持续 = 本轮剩余长度 × 等级比 |
| 缓速 | `requiem` | 白 | 时间差力场半径 +1 格 | 5 → 8 格 |
| 疾行 | `benediction` | 白 | 永久迅捷 / 跳跃等级 +1（**跳跃封顶 II**） | 迅捷 I → IV；跳跃封顶 II |
| 光辉 | `radiance` | 白 | 照射期间自己与**时间差力场圈内**的所有队友获得**「神隐」** | 神隐 6 → 10 秒 |
| 吸血 | `bloodthirst` | 红 | 光柱打掉的血按比例**吸血**回自身（不设上限），满血时溢出的治疗转成**绿心** | 吸血 15% |
| 掌控 | `dominion` | 红 | 让最近的敌人失去索敌 +5 秒（每级 +5 人、最多 15 人），并让它们**掉转枪口**去打身边的敌人 | 5 / 10 / 15 人，15 秒 |
| 光柱 | `conflagration` | 红 | 最多多发射 3 道光柱（每级 +1）；敌人够多就**一人一道**，敌人不够时多余的**堆叠**到最近的敌人身上、同一目标每多叠一道按边际递减打折 | 最多 4 道，全堆一人 ≈ 1.62 倍 |

### 几个附魔的补充说明

- **预知（黑）**：走的是和蓄力时间差力场同一个 `applyStillness`；III 级打满全程。
- **光辉（白）·「神隐」**：**就是原版隐身** —— 服务端直接把生物的「隐身」标记置上，
  模型照原版规矩消失、护甲 / 手持物照旧可见；状态栏上只有「神隐」这一条，不会平白多出一条「隐身」。
  额外只多做一件事：被隐掉期间定期把已经锁定自己的敌人甩开，**连监守者也嗅不到**。
  范围直接取时间差力场（5 格起、能被「缓速」撑大），时长按等级 6/8/10 秒。
- **掌控（红）**：连**监守者**也照样吃这一套。
- **光柱（红）**：每级多 1 道（I/II/III 最多 2/3/4 道）；4 道全堆一个人合计约 **1.62 倍**而不是 4 倍。
- **吸血（红）· 绿心**：绿心是本模组自己的抗伤池（不是原版「吸收」换色），**优先级比黄心还高**
  —— 受伤先扣绿心、扣完才轮到黄心与血量；无限时长，掉落速度随颗数指数增长（基础 1 秒/颗）。
  血条上方那条**绿心能量条**是客户端自绘的，**原版黄心不受影响、还是黄的**。

> 三顶帽子的定位：**黑 = 生存闪避、白 = 速度辅助、红 = 狂战士输出**。

## 其它机制

### 耐久

三顶帽子走一套自定义耐久：基础 **300**；**3 秒内最多磨损 1 点**（限伤）；
**1 个皮革修 20 点**（绕开原版「每个材料修最大耐久的 1/4」）。

### 附魔护甲

帽子上每多一个附魔，就给戴帽者多加 **2 点护甲**（含原版头盔附魔在内，按附魔个数算）；
摘帽 / 换帽立刻收掉。

### 音乐

每次循环开始播放该帽子对应的曲子，绑定在戴帽者身上、有距离衰减；
默认开启「自己的 BGM 优先」（同时只听一条，自己的绝对优先，其余只留最后响起的那条）。
循环被打断（摘帽 / 死亡 / 换帽 / 没有合法目标）时音乐立即停止。

### 光柱是怎么画出来的

光柱是**几何圆台**（锥壳）叠出的体积光，不是粒子；从**胯部**出发直接指向锁定的目标。
它的指向由服务端决定并同步给客户端（只在换目标时发一条很小的包），
所以画面里光柱锁的人和实际挨打的人是同一个。

## 兼容

- **Curios**（可选）：装了之后帽子也能放进饰品栏的 `head` 槽，效果和戴在头上完全一样，
  客户端也会把帽子画在头上。**没装 Curios 也能正常跑**（软依赖），只是帽子只能戴在头盔槽里。

## 自己编译

```bat
:: Forge 版（需要 JDK 17）
cd hatmod-forge-1.20.1
gradle build

:: NeoForge 版（需要 JDK 21）
cd hatmod-neoforge-1.21.1
gradle build
```

产物出现在各自的 `build/libs/` 下。两棵树都需要本机已装 **Gradle 8.x**（仓库里没有带 wrapper）。

> `*/libs/curios-*-api.jar` 是**编译期**用的 Curios API（`compileOnly`，不会打进成品），
> 放在仓库里是为了离线也能编译。
